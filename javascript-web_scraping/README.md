# JavaScript - Web scraping

Reading and writing files, making HTTP requests and working with JSON APIs in JavaScript (Node.js).

## Learning objectives

- Read and write a file with the `fs` module
- Make a `GET` request with the `request` module
- Parse a JSON response with `JSON.parse`
- Work with data from a public API (Star Wars API, JSONPlaceholder)

## Files

| File | Description |
|---|---|
| `0-readme.js` | Reads and prints a file (utf-8) |
| `1-writeme.js` | Writes a string to a file (utf-8) |
| `2-statuscode.js` | Prints the status code of a GET request |
| `3-starwars_title.js` | Prints the title of a Star Wars movie by id |
| `4-starwars_count.js` | Counts movies with "Wedge Antilles" (id 18) |
| `5-request_store.js` | Stores the body of a webpage in a file |
| `6-completed_tasks.js` | Counts completed tasks by user id |
