# JavaScript - Objects, Scopes and Closures

Classes, inheritance, scopes and closures in JavaScript, run with Node.js.

## Learning objectives

- Create an object and a class with the `class` notation
- What `this` and `undefined` mean
- Inherit from another class with `extends` and `super()`
- Why the scope of a variable matters
- What a closure is

## Files

| File | Description |
|---|---|
| `0-rectangle.js` | Empty class `Rectangle` |
| `1-rectangle.js` | `Rectangle` with `width` and `height` |
| `2-rectangle.js` | Empty object if `w` or `h` is not a positive integer |
| `3-rectangle.js` | Adds `print()` |
| `4-rectangle.js` | Adds `rotate()` and `double()` |
| `5-square.js` | `Square` inherits from `Rectangle` |
| `6-square.js` | `Square` with `charPrint(c)` |
| `7-occurrences.js` | Counts occurrences in a list |
| `8-esrever.js` | Reverses a list without `reverse` |
| `9-logme.js` | Logs arguments with a counter (closure) |
| `10-converter.js` | Converts numbers to a base (closure) |
