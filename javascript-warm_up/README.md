# JavaScript - Warm up

First steps with JavaScript as a scripting language, run with Node.js.

## Learning objectives

- Run a JavaScript script with Node
- Create variables and constants (`let`, `const`, and why not `var`)
- Data types, `if / else`, `while` and `for` loops
- Functions, recursion and scope
- Read command line arguments with `process.argv`
- Manipulate objects and export a function with `module.exports`

## Files

| File | Description |
|---|---|
| `0-javascript_is_amazing.js` | Prints "JavaScript is amazing" from a constant |
| `1-multi_languages.js` | Prints 3 lines |

| `3-value_argument.js` | Prints the first argument |
