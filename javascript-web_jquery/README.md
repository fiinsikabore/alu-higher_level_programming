# JavaScript - Web jQuery

Selecting and updating HTML elements, listening to user events and making Ajax requests with jQuery 3.x.

## Learning objectives

- Select HTML elements with JavaScript (`document.querySelector`) and with jQuery (`$()`)
- Differences between ID (`#id`), class (`.class`) and tag name selectors
- Modify the style and the content of an element
- Modify the DOM (add elements)
- Listen to user events (`click`)
- Make a `GET` request with jQuery Ajax (`$.get`)

## Files

| File | Description |
|---|---|
| `0-script.js` | Header text in red, without jQuery |
| `1-script.js` | Header text in red, with jQuery |
| `2-script.js` | Header in red when clicking `DIV#red_header` |
| `3-script.js` | Adds the class `red` to the header on click |
| `4-script.js` | Toggles the header class between `red` and `green` |
| `5-script.js` | Adds `<li>Item</li>` to `UL.my_list` on click |
| `6-script.js` | Changes the header text to "New Header!!!" on click |
| `7-script.js` | Displays a Star Wars character name |
| `8-script.js` | Lists all Star Wars movie titles |
| `9-script.js` | Displays "hello" in French (works from `<head>`) |

Each `N-main.html` file is a test page for `N-script.js`.
